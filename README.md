# 🛍️ Full Shop - Modern E-commerce App

A fully functional e-commerce web application built with React, Tailwind CSS, and integrated APIs.  
The app provides a smooth shopping experience with dynamic product browsing, cart management, and favorites functionality.

---

## Live Demo
 [View Live](https://full-shop-v6wn.vercel.app/)

---

## Overview
Full Shop is a modern online store that displays a wide variety of products across multiple categories.  
Users can explore products, add them to the cart, and save their favorite items for later.

---

## Tech Stack
-  React
-  Tailwind CSS
-  REST API
-  Vite

---

## Features
- Add to cart functionality  
- Wishlist (favorites system)  
- Products from multiple categories  
- Dynamic data fetching using API  
- Fast and optimized performance with Vite  
- Fully responsive design
